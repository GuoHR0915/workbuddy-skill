## 一、用之前需要准备三样东西

|  准备项  |                            说明                             |             缺了会怎样             |
| :------: | :---------------------------------------------------------: | :--------------------------------: |
| 表达矩阵 | count 优先；TPM/FPKM 也可，但只能做评估、GSVA、药敏，不能进 |                 /                  |
| 分组信息 |            样本名 → 分组的对应表，明确哪组是参照            | 会追问，或用样本名前缀猜（不建议） |
| 注释版本 |                    参考基因组来源与版本                     |    一定会被问，不建议让skill猜     |

如果无法提供参考基因组注释版本：
- 如果本地有定量环节直接产出的 TPM/FPKM，可以直接使用；
- ID 转换使用注释包，代价是能丢一部分 ID（转换失败）；
- "基因有效长度也可用 GenomicFeatures 包计算
若执行人既无法提供 GTF / 注释版本，也无法提供 TPM/FPKM 矩阵：停止 Count→TPM/FPKM 换算，改用 org.db 完成 ID 转换，其余依赖标准化值的分析（GSVA、药敏）标注为未执行，并在结果说明中写明原因；**不得用其他版本的 GTF 替代**。


## 二、四类常用提问模板

**① 从矩阵到差异 + 富集（最常用）**

> 用 `data/Count_matrix.txt` 做「处理组 vs 对照组」的差异分析，然后做 GO 和 KEGG 的富集。注释用 GRCh38 / GENCODE v38。

**② 已有结果，追加扩展分析**

> 在刚才的结果基础上，加做 GSVA；再用药敏预测，训练集用 GDSC2。

**③ 只做样本评估**

> 帮我看看这批数据能不能用：做 PCA、相关性热图和层次聚类，判断有没有离群样本。

## 三、三个应用范例

### 范例 A：两组差异 + ORA + GSEA

**提问**

> 用 `data/Count_matrix.txt` 做「处理组 vs 对照组」的差异分析，富集做 GO 和 KEGG，注释版本 GRCh38 / GENCODE v38。

**过程**

| 环节         | 技能做了什么                                                 |
| ------------ | ------------------------------------------------------------ |
| 数据类型判定 | 检查是否全整数、0 占比、列和分布，判定 raw count 才放行      |
| 基因整理     | ENSEMBL→SYMBOL、按平均表达去重、低表达过滤，给出进入下游的基因数 |
| 分析前评估   | PCA + 相关性热图两版（全基因 / MAD top2000）+ 层次聚类（与 MAD 版共用同一基因集） |
| 差异分析     | DESeq2，阈值 padj<0.05 且 \|log2FC\|>1                       |
| ORA          | GO BP/CC/MF + KEGG 共 4 套，**上调下调分开各做一次**，合计 8 对图 |
| GSEA         | 按 NES 正负拆成上调/下调两方向，各取方向内 p.adjust 最小 20 条；另出逐条通路图 |

**产出**

```
Produced by Bioshrimp/
├── 结果说明.md / .docx
├── program/     Step1~Step5 脚本，按序号可重跑
├── results/
│   ├── 01-数据整理/
│   ├── 02-分析前评估/
│   ├── 03-差异分析/      火山图、MA 图、DEG 热图、全量结果表
│   ├── 04-ORA/          8 对点图与条形图 + 8 张结果表
│   └── 05-GSEA/         结果表 + 上下调点图 + 逐条通路图
└── data/        中间对象 .Rdata
```

**适合**：单基因/单处理的基础文章配图，或课题前期探路。

### 范例 B：在 A 的基础上加 GSVA 与药敏

**提问**

> 加做 GSVA，基因集用 GO 和 KEGG；再做药敏预测，用 oncoPredict 的 GDSC2 训练集，看看两组哪些药敏感性不同。

**GSVA 会输出什么**

- 每个样本 × 每个基因集的评分矩阵
- limma 组间比较后的差异通路表（logFC、t、P、adj.P）
- 差异通路的 pheatmap 热图

技能对 GSVA 的规定止于"基因集口径 GO+KEGG、方法参数、pheatmap 可视化 + limma 差异"，**没有规定热图取多少条**。想固定条数（例如只画 adj.P 最小的 20 条），直接在提问里说明，技能会照办并记入说明文档。

**药敏会做什么**

- 用岭回归从表达谱预测 IC50，GDSC2 训练集为 805 个细胞系 × 198 个药物
- 逐药做组间检验并多重校正，输出预测 IC50 矩阵、差异药物表、火山图与箱线图

**注意**

- 药敏预测的训练集是**肿瘤细胞系**。样本若是正常组织或非肿瘤细胞，结果只能当相对趋势看，不能直接读成临床药敏
- 样本量小时检验效能有限，`padj` 要和效应量一起看
- 预测值的绝对值（ln µM）不可与实测 IC50 比较，只能做组间相对比较
- 这一步在整条流程里最慢：198 个药逐个做岭回归，且该包在 Windows 上无法并行

### 范例 C：只想知道这批数据能不能用

**提问**

> 先别做差异，帮我评估一下样本结构，看有没有离群。

**过程**

出三张图，并给出可判读的数字：

- PCA 的 PC1/PC2 方差解释比例
- 组内与组间的平均 Spearman 相关系数
- 层次聚类的分支是否与真实分组一致

**判读原则**

| 现象                     | 处理                             |
| ------------------------ | -------------------------------- |
| 两组沿主轴分开、组内聚集 | 结构良好，可继续                 |
| 某样本单独成支           | 疑似离群，先查 RNA 质量或批次    |
| 组内相关明显低于组间     | 重复性不足，差异结果不可靠       |
| 聚类分支与真实分组不一致 | 存在混杂因素，差异分析结论不可信 |

技能对这一步的表述是：**三张图分不开时，差异分析结果不可信，应先排查离群样本与混杂因素**。它不会硬跑。

## 四、产出物怎么用

**1. 图表直接取用**
`results/` 下按步骤分文件夹，每个步骤的图与表只进自己的目录。图以 PDF 输出，表同时给 `.xlsx` 与 `.txt`——后者是防 Excel 把 `MARCH1` 改成 `1-Mar` 这类基因名。

**2. 方法学描述照抄**
`结果说明.md`（及同内容的 `.docx`）里写清了每步参数、阈值、包版本、参考基因组与基因集版本。写 Methods 时可直接改写。

**3. 复现靠脚本**
`program/` 里是本次实际运行的脚本，按 Step 序号顺次执行即可重跑；含随机性的步骤都设了固定种子，中间对象以 `.Rdata` 落盘。

## 五、常见追问怎么提

| 你想改的           | 直接这样说                                                   |
| ------------------ | ------------------------------------------------------------ |
| 放宽/收紧差异阈值  | 阈值放宽到 1.5 倍差异                                        |
| 换参考注释         | 注释改用 hg19 / GENCODE v19，重跑                            |
| 加免疫浸润         | 加做 CIBERSORT 和 ESTIMATE，看看两组免疫微环境差异           |
| 限制逐条通路图数量 | 逐条通路图只出每个方向最显著的若干条（技能默认为全部显著通路） |
| 换分组对比         | 改成 A 组 vs C 组重跑差异，其余不变                          |
| 出中文图           | 图内文字改成中文（投稿图仍建议英文）                         |

## 六、六个容易踩的坑

1. **拿 TPM 当 count 喂进去**——它不会报错，会给你一堆地基错误的 p 值。技能会拦，但别绕过。
2. **不给注释版本**——这不是啰嗦。换个注释版本，基因数和富集结果都会变，事后无法追溯。
3. **每组样本过少**——DESeq2 仍能跑，但离散度估计不稳定，结论只能算探索性。
4. **期望"所有显著通路都出图"**——GO 的显著条目可能达数百上千条，全量出图会产生大量 PDF。合理做法是限制条数，并把这次裁剪写进说明文档。
5. **把药敏预测当实验结果**——它是基于细胞系的统计推断，不是药敏试验。
6. **只看 p 值不看效应量**——大样本下微小差异也会显著。差异分析请同时看 log2FC，药敏请看预测值的组间差与倍数。

## 八、一句话建议

第一次用，建议先拿一批**已知结论的数据**（比如有公开发表结果的 GEO 数据集）跑一遍，核对差异方向和通路富集是否与原文一致。确认流程可信之后，再上自己的数据。

这比直接跑自己的数据、然后花两周怀疑结果，要快得多。
